# Customer Shopping Behaviour Analysis

##  Project Overview

Customer Shopping Behaviour Analysis is a data analytics project that focuses on understanding customer purchasing patterns, shopping preferences, spending habits, product performance and customer segmentation.

The project uses **Python, PostgreSQL, SQL and Microsoft Power BI** to transform raw shopping data into meaningful business insights and interactive visualisations.

The primary objective is to analyse customer behaviour and help businesses make data-driven decisions related to marketing strategies, customer retention, product performance and revenue growth.

##  Project Objectives

- Analyse customer purchasing patterns and spending behaviour.
- Compare total revenue generated by different genders.
- Identify the top-rated products based on customer reviews.
- Compare average purchase amounts across shipping methods.
- Analyse subscriber and non-subscriber purchasing behaviour.
- Segment customers into New, Repeat and Loyal categories.
- Understand purchasing patterns across different age groups.
- Develop an interactive Power BI dashboard for business insights.

## 📂 Project Workflow

### 1. Python – Data Cleaning and EDA

The project starts with importing the customer shopping dataset into Jupyter Notebook.

**Activities performed:**

- Imported the dataset using Pandas.
- Examined dataset dimensions and data types.
- Identified missing values.
- Handled missing Review Rating values using category-wise median imputation.
- Standardised column names.
- Performed exploratory data analysis.
- Analysed payment methods and purchase frequency.
- Prepared the cleaned dataset for database integration.

### 2. PostgreSQL – SQL Analysis

The cleaned dataset was imported into PostgreSQL and stored in a table named `customer1`.

SQL queries were written to perform business analysis.

**Key SQL operations:**

- SELECT and WHERE
- GROUP BY and ORDER BY
- Aggregate functions (SUM, AVG, COUNT)
- CASE statements
- Common Table Expressions (CTEs)
- Filtering and customer segmentation
- Revenue and purchasing analysis

**Business queries performed:**

1. Total purchase amount by gender.
2. Top 5 products based on average review ratings.
3. Average purchase amount comparison between Standard and Express shipping.
4. Average spending and total revenue comparison between subscribers and non-subscribers.
5. Customer segmentation into New, Repeat and Loyal customers.
6. Repeat customer analysis based on previous purchases.
7. Customer distribution across different age groups.
8. Age-group revenue contribution analysis.

### 3. Power BI – Interactive Dashboard

The final stage involves developing an interactive dashboard using Microsoft Power BI.

**Dashboard objectives:**

- Display important business KPIs.
- Visualise customer purchasing behaviour.
- Compare revenue across customer categories.
- Analyse product ratings and preferences.
- Understand subscription patterns.
- Visualise customer segments.
- Compare spending patterns across shipping methods.
- Explore age-group performance.

**Key dashboard components:**

- KPI Cards
- Bar Charts
- Column Charts
- Donut Charts
- Line and Column Charts
- Interactive Slicers
- DAX Measures

## ⚙️ Installation and Setup

### Step 1: Clone the Repository

```bash

cd Customer-Shopping-Behaviour
```

### Step 2: Install Python Libraries

```bash
pip install pandas numpy matplotlib seaborn sqlalchemy psycopg2-binary jupyter
```


Open the project notebook and execute the cells sequentially.

- Create a database.
- Import the cleaned dataset into the database.
